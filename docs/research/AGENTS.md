# AGENTS.md — docs/research

For docs-wide rules see [../AGENTS.md](../AGENTS.md).

This folder stores **research notes** that capture concrete demand
signals for vertical accelerators (CONSTITUTION §4 / VISION).

## Invariants

- **No invention.** If a claim is factual, it must have a source URL.
- Prefer primary sources (policy docs, surveys, peer-reviewed papers).
- Write in an agent-usable style: bullets, “so what”, explicit next steps.
- Never include sensitive personal data. Anonymize names/emails.
- Date-stamp notes in the filename: `YYYY-MM-DD-...`. Use kebab-case.

## What a good note contains

- Vertical(s) considered.
- Demand signals (numbers + citations).
- Constraints (privacy, a11y, i18n, procurement, integration surfaces).
- Implications for Convergio: required template params, evidence kinds,
  domain gates.
